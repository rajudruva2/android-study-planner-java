# Study Planner — Android Java Demo

A small native Android app written in Java, designed for mobile CI/CD practice.

## Features
- Native Android Activity and simple sample-data UI
- Gradle Android build configuration
- GitHub Actions workflow to build a debug APK and upload it as an artifact

## Build with GitHub Actions
1. Push this project to a GitHub repository with the `main` branch.
2. Open the **Actions** tab.
3. Push a commit or manually run **Android Java Build**.
4. Download the artifact `android-study-planner-java-debug-apk`.

## Build locally
Open this folder in Android Studio, sync Gradle, and build the debug APK.

## DevOps practice
Try adding tests, release builds, APK/AAB signing with GitHub Actions secrets, tester distribution, and deployment approvals.
